# World English Bible source

These USFM files are the 66-book `engwebp` edition downloaded from eBible.org.

- Source: https://ebible.org/details.php?id=engwebp
- Archive: https://ebible.org/Scriptures/engwebp_usfm.zip
- License: Public Domain
- Retrieved: 2026-10-15

The importer strips USFM formatting, Strong's annotations, cross-reference notes, and footnotes without changing the displayed verse wording. Run `npm run db:seed` before `npm run db:import:web`.
